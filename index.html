Zero-compromise on-device expense & account intelligence

SpendTrack eliminates the privacy hazard of cloud fintech apps. By running completely on-device with zero network permissions, it provides deep analytics, loan tracking, budget calculations, and automated statement parsing directly inside Android's sandbox.

  • Deterministic Statement Parser: Ingests Kotak Mahindra & Slice credit card PDFs locally without third-party APIs.
  • Atomic Balance Corrections: Rollbacks and recalculations for multi-account debts and shared expenses.
  • Integer Paise Precision: Replaces IEEE 754 floating point arithmetic with exact 64-bit integer calculations.

ARCHITECTURAL NOTES ON NATIVE COMPUTING

Software built as durable physical furniture: quiet, local, and engineered to last.

The prevailing software culture treats the client device as a dumb terminal for cloud subscription infrastructure. Applications have become fragile, bloated by megabytes of remote telemetry, and rendered sluggish by generic cross-platform abstraction layers.

I build with a different conviction: software should be sovereign, fast, and permanent. A smartphone is a supercomputer in a pocket; when we execute computations locally with disciplined native code, interfaces become instantaneous and users reclaim total custody of their life data.
