# Changelog

## 2.0.0 — 2026-10-31

### Added

- Savings account interest settings and posting, shared expense splits, and richer settlement tracking.
- Light, dark, system, and true black appearance options.
- Transaction report exclusions and improved statement import review and editing.
- Expanded transaction, account, budget, fixed deposit, recurring payment, and chart workflows.

### Changed

- Upgraded the local database to schema version 11 with migrations that preserve existing data.
- Refined dashboard, transaction, chart, and management screen layouts.
- Improved reminder preferences and transaction/account balance handling.

### Fixed

- Deleting or editing a loan repayment now keeps the repayment transaction, account balance, and loan balance in sync.
